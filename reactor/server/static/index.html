Sample bias follows the electron beam: pre-start arms the supply at this level but leaves its output off, and each beam brings it on a lead time early and drops it a trail time late (both in Advanced timing). That leaves the stage unenergised for the rest of the cycle, so the stage thermocouple reads clean whenever the beam is off. A reignite does not cycle it. Zero here means the supply is never switched on at all.
Enter a magnitude — the supply cannot source a negative voltage, so the polarity toggle records which way you ran the leads onto the stage and signs the logged voltage. Its current limit stays whatever you set on the supply's front panel.

Overlap is how long the incoming gas starts before the outgoing one stops. The same value applies at every handoff — First to Second, and Second back to First.
Simultaneous means the gases do not divide the window at all: every gas set to it flows for the whole window at its own rate, so the % is greyed out. It takes two — setting only one gas to Simultaneous is refused when you press Start, since a lone one is almost always a half-finished edit. They still lead the beam in by the overlap.
MFC 1/MFC 2 turn on automatically around the beam exposure instead of running the whole cycle. Percentages cover the beam's lit exposure time, freezing along with the exposure clock during a reignite or a pause. "First" also leads the beam's start by the overlap, off wall clock during dose/pump A. Both gases go off when the exposure ends.
EE-CVD has no beam step, so the percentages cover a whole cycle (dose + pump A) instead. Pump A and the gas clock both freeze while the plasma is out, so the windows stay locked to the cycle however often it reignites. The dose is never frozen — a paused precursor pulse would hold the dose valve open. "First" re-arms by the overlap before the cycle ends, which is the same handoff wrapping into the next cycle.

Flag tolerance only warns — fill pressure drifting past it raises an event, it never stops or changes the run.
Beam strike and reignite
Sample current below min beam current is what counts as the plasma being out, and is what triggers a reignite.
Reignite settle is also how long the initial strike is given to draw current before it counts as a failure — the first flip of the plasma ground is always required to start the beam, so it is never reported as a reignite.
Sample bias bracket
How far ahead of the beam the sample bias comes on, and how long after it goes off. The lead runs down inside pump A and the trail inside pump B, so bracketing the beam does not make a cycle any longer. A reignite does not cycle the bias. In EE-CVD the beam is one long step, so the bias leads the strike at the start of the run and drops after the beam at the end of it.
Ar pneumatic soft open
The Ar pneumatic is never opened in one flip — it is pulsed this many times, this wide, this far apart, and only then left open, so the Ar built up behind it bleeds in instead of dumping. It applies to every open of that valve: the Hardware tab, pre-start, and the recipe. Zero pulses turns it off and an open becomes one plain flip again.
One pulse is the default: the pneumatic is too slow for a short command to move it far, so more pulses just meant more inrushes.
End of run
At the end of a run the Ar setpoint is zeroed, this delay runs, then the Ar pneumatic closes. The run then parks with the plasma ground OFF (beam-on mode).
