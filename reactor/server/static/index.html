Overlap is how long the incoming gas starts before the outgoing one stops. The same value applies at every handoff — First to Second, and Second back to First.
H2/N2 turn on automatically around the beam exposure instead of running the whole cycle. Percentages cover the beam's lit exposure time, freezing along with the exposure clock during a reignite or a pause. "First" also leads the beam's start by the overlap, off wall clock during dose/pump A. Both gases go off when the exposure ends.
EE-CVD has no beam step, so the percentages cover a whole cycle (dose + pump A) instead. Pump A and the gas clock both freeze while the plasma is out, so the windows stay locked to the cycle however often it reignites. The dose is never frozen — a paused precursor pulse would hold the dose valve open. "First" re-arms by the overlap before the cycle ends, which is the same handoff wrapping into the next cycle.
Advanced timing
Flag tolerance only warns — fill pressure drifting past it raises an event, it never stops or changes the run.
Reignite settle is also how long the initial strike is given to draw current before it counts as a failure — the first flip of the plasma ground is always required to start the beam, so it is never reported as a reignite.
Ar close delay: at the end of a run the Ar setpoint is zeroed, this delay runs, then the Ar pneumatic closes. The run then parks with the plasma ground OFF (beam-on mode).
Pre-startidle
Run name prefixes every file this run writes (trace, by-cycle, parameters, ellipsometer), e.g. Mo-014_260817_142530_run.csv. It pre-fills from the last run you actually started, incremented — start Mo-014 and the next one offers Mo-015. Editing it here is enough; there is nothing to confirm.

Opens the Ar pneumatic, waits, flows Ar, starts the precursor fill pulse, then runs the reignite protocol until sample current appears and holds it. The strike retries indefinitely — it stops only when you press Stop pre-start. However it ends, the beam is grounded on the way out; Ar and the fill pulse are left running.

Abort pre-start is the undo, and stays available after the plasma has struck: it stops Ar (flow then isolation valve), stops the fill pulse and closes the fill valve, returns the beam relay to de-energised, and commands the HV supply off — one click.
