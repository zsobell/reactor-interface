Ellipsometer sync —

Drop in the refit file you downloaded from the FS-1, pick this run's sidecar and reactor run: you get every reactor channel and every FS-1 measurement on one cycle-number axis, with reignite-paused samples dropped. The result is saved into the data folder and loaded into the plots below immediately — no save-then-drag step.
It is a union of instants, not a resampling: each source keeps its own rows at its own times and is blank in the other's columns, so every number in the file is one that was really measured — which is why those columns are sparse, and why a plot draws one line through the cells that have values rather than breaking at the blanks. The only derived number is an FS-1 row's cycle_number, read off the reactor's own time→cycle curve; a point taken while the run was paused, or outside the cycling window, is dropped rather than given a position the tool was never at.
