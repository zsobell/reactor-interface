# Claude project entry point

Follow [AGENTS.md](AGENTS.md) for the shared project instructions, Beads workflow,
hardware authority, testing requirements and conservative Git policy.

Start with [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) for the environment and
change-to-test map, then [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for ownership.
Read [docs/CONTROL_MODEL.md](docs/CONTROL_MODEL.md) before changing control logic.
Hardware facts belong in [docs/HARDWARE.md](docs/HARDWARE.md) and the device
references it links; run semantics belong in [docs/RUN_PROGRAM.md](docs/RUN_PROGRAM.md).

Current work and session context live in Beads: `bd prime`, `bd ready`,
`bd memories reactor`. Historical conversation notes are not a replacement for
current code, tests or operator-confirmed behavior.
